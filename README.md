# Medical Diagnostics – Feature Engineering & Preprocessing Pipeline

## Project Overview
This project focuses on building a reusable Machine Learning preprocessing pipeline using the Mammographic Mass dataset from the UCI Machine Learning Repository.

## Objectives
- Handle missing values using SimpleImputer.
- Encode categorical features using OneHotEncoder.
- Scale numerical features using StandardScaler.
- Implement ColumnTransformer and Scikit-Learn Pipeline.
- Prevent data leakage using train-test splitting.
- Perform correlation analysis.
- Identify important features using Mutual Information.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
UCI Mammographic Mass Dataset

## Project File
`Medical_Diagnostics_Feature_Engineering.ipynb`

## Conclusion
This project demonstrates a reusable data preprocessing workflow for preparing medical diagnostic data for machine learning applications.
